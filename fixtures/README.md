# Fixture pengujian

Semua fixture dalam folder ini **sintetis**, memakai waktu tetap dan koordinat contoh untuk pengujian kontrak. Fixture bukan deteksi NASA nyata atau laporan kondisi udara saat ini. Aplikasi tidak boleh menampilkan fixture sebagai data operasional tanpa mode demonstrasi yang dilabeli secara eksplisit.

Data geografis di src/data merupakan dataset Natural Earth nyata dengan manifest sumber tersendiri, bukan deteksi hotspot atau data kualitas udara.
