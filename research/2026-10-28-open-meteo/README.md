# Open-Meteo M3 response evidence

Respons publik untuk contoh lokasi tetap Palangka Raya (-2.21, 113.92). URL, hash dan waktu evaluasi ada pada provenance.json. Ini bukti historis model saat diambil, bukan kondisi terkini atau fixture sintetis. Tidak dipakai sebagai cache operasional atau dimuat antarmuka.

`npm run replay:air` memeriksa hash, memproses respons pada waktu evaluasi historis, lalu menguji cache disk sementara tanpa jaringan. Perintah ini berbeda dari konektivitas runtime aplikasi. Folder research tidak disertakan dalam arsip source checkpoint; salin terpisah jika perlu mereproduksi bukti ini.
